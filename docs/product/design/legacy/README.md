# Legacy wireframes

These seventeen annotated wireframes (`mac-*`, `iphone-*`, `pwa-*`) were last
redrawn on 2026-09-17, for the second IA ruling. That was before round B
(2026-09-19) repainted the palette, so they still use the colours it replaced:
`#f6f7f9` ground, `#2b5fd0` accent, `#12171c` ink, and six fills no token ever
held. The round-0 design canvas boards supersede them (`HANDOFF.md` §0). They
are kept for history and are not repainted. For that reason,
`ops/scripts/build-design-tokens.mjs --check` exempts this directory from its
every-hex-is-a-token rule, and it names the exemption in its output. Older
documents — `design-system.md`'s wireframe table, `preview.html`, review-00,
`app-ux-plan.md` and dated research notes — still cite them as
`docs/product/design/<name>.svg`. The file names have not changed, so each one
is here.

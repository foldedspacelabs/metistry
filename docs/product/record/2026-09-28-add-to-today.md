- 2026-09-28 — **Add to Today reaches the console.** T4-24 shipped the Linear sync and the capture service that turns an assigned issue's mirrored request into today's task line, but no route called it — the Mac's *Add to Today* control has sat disabled since, printing "this build can't add a tracker's tasks to Today from here yet." Ruling 11 (W2 checkpoint, 2026-09-27) closes that gap: `POST /api/today/add` takes the mirrored request's own key and calls T4-24's service unchanged, idempotent per issue and refusing any day but the owner's current one — Add to Today means today, never a date a client might get wrong. Safe to leave running because the write path (the capture service, its idempotency, its refusal to touch the owner's own notes) is entirely T4-24's, already tested; this ticket only wires the door onto it.

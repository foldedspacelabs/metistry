- 2026-09-28 — **Metistry can answer a calendar invitation — and nothing but the owner's own answer changes.** An iCloud, Fastmail or any RFC 6638 CalDAV account is a connection signed in with an app password (never the account's own, never in a URL or a file — filled as Basic sign-in at the egress door, for the listed host only). Its sync puts the owner's two weeks on Today beside every other calendar, with the owner's own answer, found by the addresses the server says are theirs. A reply is a text edit of the server's copy that changes exactly one line per event — the owner's own attendee line — so the server itself sends the organizer the reply; every other byte is the server's, proven against a local CalDAV server. Changing an event is limited to ones nobody else is in, and every change is previewed and then confirmed against the exact version previewed. Google's CalDAV is refused by name — it takes OAuth only — and waits for Google sign-in (T4-13).

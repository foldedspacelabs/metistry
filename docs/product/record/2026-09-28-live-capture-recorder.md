- 2026-09-28 — **Meeting audio can be recorded without the assistant ever being able to start a recording, and a recording hears only the apps the owner chose.** The live-capture helper takes app audio through a Core Audio process tap. A tap mixes exactly the processes its description names, and the helper builds that description in one function. The function takes a list of bundle IDs, has no way to say "everything except", and refuses an empty list. A test has app X and app Y both playing and checks that only X reaches the transcript. The bridge has two credentials. The one a tool caller holds reaches `check` and `status`, both reads. Start, stop and Keep Going answer only the owner's control credential; the tool credential gets 403 there, and the bridge will not run if the two are the same. Transcription happens on the Mac as the audio arrives (`SpeechTranscriber`, macOS 26). The helper enforces the working-day limits on its own clock, so a recording stops at ten hours even with nothing else running.

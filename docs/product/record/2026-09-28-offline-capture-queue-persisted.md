- 2026-09-28 — **A capture queued offline no longer disappears if the Mac app quits.** T5-5 shipped the composer's offline queue in memory only, so a capture still waiting to send when the app quit was gone — the owner's words, lost, with no record they were ever typed. Ruling 19 approved a store beyond `app-preferences.swift`'s settings allowlist for exactly this: `JSONCaptureQueueStore` writes each queued capture's text, key and instance to one JSON file under the app's own Application Support directory the moment it goes offline, and reads it back at launch, resending through the same gate with the same `Idempotency-Key` so the console dedupes a replay exactly as it would have before the relaunch. Safe to leave running because nothing but a still-queued capture is ever written there — a sent one is gone the instant it lands, and an instance switch clears only its own entries, leaving every other instance's queued work untouched.

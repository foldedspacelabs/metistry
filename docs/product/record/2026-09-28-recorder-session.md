- 2026-09-28 — **A recording now reaches Metistry on its own, and what it heard is answered only on the Mac.** When a recording ends, however it ends — the owner's Stop, the ten-hour stop, a full disk, or the recorder crashing mid-meeting — its transcript goes to the inbox through the same capture door every other capture uses, keyed so a retry can never make a second copy, and marked delivered only once the console has answered with a row: a console that is down or refuses the credential leaves the transcript waiting on the Mac, never lost. A crash keeps everything up to the moment it happened and puts exactly one report in Needs You. The recorder is a separately signed bundle with its own launchd job, so the microphone and app-audio grants belong to it and survive a rebuild, and it exists only on an install that asked for live capture. And the private tier is now enforced where turns run: any assistant turn that belongs to a recording runs on an on-machine model whatever was chosen for it, and with none assigned it is refused with the command that fixes it — it never quietly falls back to a cloud model.

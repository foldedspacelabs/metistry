- 2026-09-28 — **Releases publish whole from the public repository: npm packages carry provenance, and a GitHub release is never frozen incomplete.** Every published `package.json` now names the repository it is built from, so npm accepts the sigstore provenance that ties each `@foldedspacelabs/metistry-*` tarball to the public CI run that built it (v0.15.0 was refused, E422); a check holds every package to it in CI, before a release can find out. With immutable releases on, a release is built as a draft carrying every asset and only then published, and a failed Mac app or appcast holds it as a draft rather than shipping it without the DMG for good — "Re-run failed jobs" completes it. Safe to leave running because every failure it cannot fix is now loud: a provenance rejection fails the npm job instead of passing as a skip, a published release missing an asset fails with the remedy, and a malformed notarization key is refused naming the format it must be.

- 2026-09-28 — **An agent's report can be kept, and an agent that asks can learn the answer.** Since reports stopped taking Approve (T2-3), a finding an agent filed could only be dismissed, and the evening fold — which turns what the owner kept into knowledge — had nothing left to read of them. A report now carries **Acknowledge**: one press, no words, nothing fires, and the fold picks it up that night; an event's report (a failed routine's Try Again) keeps its own act instead. The other half closes a loop agents never had: an agent that asked the owner a question, or filed a report, reads back where the answer stands by repeating the same request — the owner's choices and words per question, or that the report was acknowledged or dismissed. Enforced at the tool: the lookup is keyed on the asking credential alone, so an agent that echoes another agent's question exactly gets a new question of its own, never the other's answer — and it cost no new tool on a surface already at its ceiling.

- 2026-09-28 — **A suggestion about a routine is a request, and only the owner's Approve changes the routine.** A routine suggestion is an `improvement` in Needs You carrying one `.metistry/scheduled.yaml` entry before and after, with the words the owner reads drawn from those entries. Raising one writes nothing; Later, Revise and Decline write nothing; Approve writes exactly the "after" through the same Scheduled door the owner's own edits use, as `user`, compare-and-swap, and is refused `stale` — nothing written — if the entry moved since, or if the words no longer match what the entries draw. It can only change when something runs (a schedule, a pause, a sync's cadence or raise toggles): what runs and a sync's connection are refused at the tool, and an agent's request changes nothing. Safe to leave running because every refusal is a code path with a test, not a promise in a prompt.

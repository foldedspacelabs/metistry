- 2026-09-28 — **A task line becomes a Linear issue, and the issue is never filed twice.** *Send to Linear* files the issue from the line's own text through the owner's Linear connection, then writes `linear:<KEY>` on the line. The issue's id is derived from the task itself, so a second press, two devices pressing at once, or a retry after a lost answer all land on the same issue — with nothing stored but the note. The line is only written if it still says what the owner saw; if they edited it in the meantime, nothing is written and the issue is not re-created.

- 2026-09-28 — **A `.metistry/` commit can no longer reach an agent bearer through file history.** `GET /vault/show` has refused a protected or non-vault path for every caller since T10-4, but its sibling `GET /vault/log` did not: a path-scoped request for a protected file, or a whole-tree read that happened to include a commit touching one, handed that commit's subject and provenance trailers to whichever bearer asked — including the console's, which is what fronts an agent. The reconciler's `vault.log()` now takes the caller class and narrows the same way `show` does, but to the owner bearer rather than to nobody: every other caller gets `403 forbidden` for a protected `path`, and a whole-tree read drops any commit that touched one outright rather than redacting it. Safe to leave running because it is enforced at the bridge itself, not by trusting the console's own `/api/knowledge/history` gate to keep asking it correctly — a caller that reached `GET /vault/log` some other way was always the real risk this closes.

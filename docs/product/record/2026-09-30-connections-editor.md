- 2026-09-30 — **Any service a manifest describes gets a form on the Mac, and no secret is ever typed into it.** Settings ▸ Connections ▸ Add Connection starts with the type, offers the connection types the instance has installed — the product's and the owner's own extensions alike — and renders a known service's form from its manifest's fields: a field of each closed kind has one drawing, so a stranger's extension appears with the same form as a shipped service and nobody writes Swift for it. A secret is picked by name from the secrets the instance already holds, or stored first through the Secrets sheet; the same *What it sends* check the door makes draws on the draft, so a key headed somewhere it may not go shows blocked before anything is written. Every add and every change is one `metistry connections` command shown in full before it runs, and the CLI judges each field against the manifest — a secret on a command line is refused and never echoed. The two doors this needed — the installed types on the list route, `--config` on the CLI — added no route and no new verb.

- 2026-09-30 — **Agents reach APIs, feeds, folders and OAuth services through Metistry, and the proxy answers on a live console.** Until now the two proxy tools were built, tested and unplugged: no running console held a connection pool. It holds one now, over the instance's own connection files, so an agent the owner lent a connection can list and call it for real — through the same door that fills a key only for the hosts it may go to and redacts it on the way back. A service that is not an MCP server gets tools Metistry writes for it — read a feed, GET or POST an API under its own URL and nowhere else, list and read a folder without ever leaving it — each starting at Ask First. Signing in with OAuth is the owner's hand alone: one command opens the browser, listens on this Mac's loopback for exactly one answer, checks it is the answer it asked for, and keeps only the refresh token, in the Keychain; the assistant has no path to start one. Every connection an agent reaches now shows in its permissions table, marked as reached through Metistry. Found and closed on the way: a secret reference an agent wrote into a tool's arguments would have been filled by the door and sent upstream; it is refused before anything is dialled.

- 2026-09-30 — **Metistry can read who wrote and draft the reply — and no code path can send mail.** A Gmail account (2-Step Verification and an app password) or any IMAP server is a mail connection; the app password goes only to the exact server and port the owner listed, only over TLS, only when granted, and never into a file, a URL, a log or an error — a server that echoes it gets its name back. The IMAP client knows nine commands, each with one fixed shape, so sending, moving, flagging or deleting mail is not a path it has; reading opens a mailbox read-only and fetches a fixed set of headers, never a body, stamped as comms so the data policy keeps it on the Mac; a draft is previewed, then appended to Drafts only if it is exactly the draft previewed — the owner sends it. Proven against a local IMAP server that records every command it receives (T4-15).

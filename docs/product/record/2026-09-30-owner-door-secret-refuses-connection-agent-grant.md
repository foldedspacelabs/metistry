- 2026-09-30 — **An owner-door secret refuses a connection or agent grant, at the tool.** `github_write` — the owner's own fine-grained GitHub token, posted only by the console's PR doors — could until now be granted to `connection:*` or `agent:*` in `.metistry/secrets.yaml`, refused only by convention (`docs/ops/cli.md` even documented it as valid), which would have handed a connection's stdio child or an agent the raw token to call GitHub directly, bypassing the doors' head-SHA, staleness and self-review guards entirely. `secrets.yaml`'s own schema now refuses a hand-written grant on an owner-door secret, naming the fix; `metistry secrets grant` refuses writing one; and `secretGrant` itself reads Off for one no matter what a file says, so a file from before this change still cannot deliver it through a command connection's environment or `guardedFetch`. Safe to leave running because the owner door (`apps/console/src/github-write.ts`) never consults a grant to read its own secret — only its *Sent only to* host list — so none of the three refusals touch it.

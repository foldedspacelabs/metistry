- 2026-09-30 — **A push says a request needs you, and never what it says.** The console used to push every message it wrote — a reply, an ack, a brief, an alert — with the first 160 characters of its text; the PWA's worker stopped showing that text (T7-5), but it still left the console for the push service. Now only Needs You pushes (screen 18 §6): a request just raised, or one whose Later has run out, sent as its type from a closed table, the fixed title "Needs You", and a link that opens that card. A request's own title is written by whoever raised it and can hold a key or a code, so it is never sent; the wire function copies three fields and no other, so a body cannot ride along even in a caller that casts past the type. Safe to leave running because it only removes what leaves: activity is read where it always was, in the thread and the feed, and a burst — a sync's first pass — is one push for the queue rather than a lock screen full.

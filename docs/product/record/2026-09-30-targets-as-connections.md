- 2026-09-30 — **Sending a task to Devin or opening a GitHub issue now goes through the same door as every other connection, and the syncs that bring the answers home read the same connections.** A target used to hold its key as an environment variable the console read and put on the request itself; now Devin and GitHub Issues are agent connections, and each request is sent through the connection's own egress door — the key filled only for the hosts its *Sent only to* list names, only when the owner granted it to that connection, and redacted on the way back. What a brief may carry is still the connection type's data policy, so a connection file cannot widen it, and a brief that tries to smuggle a secret reference for the door to fill is refused before anything leaves. Devin's purposes — work and knowledge research, with the words that frame each — moved from code into the Devin connection type, where an owner can add one without a release. GitHub, Devin Sessions and Devin Knowledge read their connections the same way; a broken connection fails the run by name instead of quietly falling back to an older key, and those old keys keep working for one release so nothing stops on update.

- 2026-09-30 — **The floating bar shipped: a second interface that lets the owner say something to the assistant, jot a note or a to-do, or start a recording without leaving what they are looking at — and it holds no power an agent could borrow.** It exists only while the live-capture recorder is installed and answering; one click opens Ask (the same conversation as the window's Chat), Note or To-do (saved with Return, anchored to the recording's session and second when one is running), or Record, whose start names only a mode — the macOS picker the recorder presents is the one thing that chooses a window or a screen. The recording's liveness is carried by the one slow breath the design system admits, which holds still under Reduce Motion, and by the senses actually open, never by what was asked for. The bar drives the recorder with a control key only the owner's Mac holds — read from the one Keychain item the CLI writes, sent to the loopback recorder and nowhere else, never printed — while the recorder's tool-facing key, the one any agent could present, reaches reads only; a missing or wrong key turns Record off with the reason and the two commands that fix it. One promise from the design is deliberately not drawn yet: *staying on this Mac* for a question asked mid-recording, because nothing in the message route can yet carry the session that would make the assistant enforce it.

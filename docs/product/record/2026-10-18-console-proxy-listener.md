- 2026-10-18 — **The console now has a listener that is remote by construction, so the Mac's own owner token can never be carried through a tunnel.** Every way a phone will reach a Mac from outside — Tailscale Funnel, Cloudflare Tunnel, zrok, ngrok, a forwarded port with TLS ended on the Mac — runs an agent on the Mac that dials the console from `127.0.0.1`, and the loopback-only local owner token (the credential the Mac app and the command line use, which may mint agent bearers) would have been honoured for anything that agent forwarded. Rather than a cleverer address rule, which no proxy's peer address can support, the console gained a second listener for proxies only: a 0600 Unix socket and a loopback port a provider is pointed at, on which the token is refused from every peer and the refusal recorded, no `local` route answers, and a request must name the remote host the install is configured for or is turned away before anything else looks at it. The main listener is unchanged, nothing is weaker when the proxy listener is absent, and there is no configuration that opens the local door on it — the decision is made from the socket the server accepted, never from a header.

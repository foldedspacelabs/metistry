- 2026-10-18 — **The Mac app's copies of core's rules can no longer drift unnoticed.** The app carries three of core's decisions by hand — what widens an agent's autonomy (the owner's confirm lists exactly core's words) and what counts as a key-shaped value (checked before a value ever reaches a command line), and which hosts count as loopback (so plain http to them is not called unsafe). All three used to be "held to core" by cases copied into the Swift tests, which keep passing after core changes until someone recopies them. The cases now live once, in a file core's own tests run through the real functions and the app's tests run through the copy, and a CI check keeps both reading it and the Mac job running when a case moves. Wiring them up found a real gap on the first run: core gives connection calls their own autonomy rule, which the app's copy does not model yet.

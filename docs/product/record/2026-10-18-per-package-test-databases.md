- 2026-10-18 — **Every package's tests run in a database of their own.** The root `pnpm test` used to run all twenty-odd packages against one scratch database, and a `--no-file-parallelism` on that line never reached vitest; suites owned their rows by marker, and the W4 wave still saw the same cross-package flakes (morning-brief, tasks' `external_ref`, reply-review's FK, linear-order, push-needs-you), because a marker protects only the rows a suite remembers to mark. `ops/scripts/test-workspace.mjs` now copies the migrated scratch database once per package (`TEMPLATE`, through core's `recreateScratchDb`, so every name is validated the way `testDb()` validates it and never an install's), runs the package there and drops the copy. Two packages' DB suites run side by side on different databases (`--concurrency 2`).

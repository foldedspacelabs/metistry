- 2026-10-18 — **Configuring the recorder leaves no owner-hand step.** Setting `METISTRY_LIVE_CAPTURE_URL` and running `metistry up` now makes all three credentials the recorder needs — the bar's control key (in the login Keychain, where the Mac app reads it), the bearer the router presents to the live-capture bridge, and the capture owner token the bridge posts transcripts with (recorded in the console by hash, labelled `live-capture`) — before the bridge is started, so it starts holding them. Nothing is ever replaced: an existing Keychain item stands, an owner-pasted `.env` value is adopted into the Keychain, and a rerun changes nothing; a rebuilt database is repaired by the next `up` without rotating the token. The values are never printed and never on a command line, and an install that never asked for a microphone gets none of the three.

- 2026-10-18 — **Dispatch has one way in, and a key in the environment is not it.** GitHub Issues and Devin were reachable two ways for one release — as a connection, whose key the egress door fills only for the hosts its owner listed, and as a `targets/` manifest with an `env:` key the console read straight from its environment. 0.17.0 removes the second: an environment key alone dispatches nothing (the target does not exist), a `targets/` manifest but the crews' `local-crew` is refused at load, and `metistry doctor` names any key still set and the one verb that replaces it. What dispatch can reach is now exactly the audited connections; the path that could put a credential anywhere a manifest pointed is gone, and a test pins that it stays gone.

- 2026-10-19 — **One command now wires Claude Code to the vault in both directions, and the secret that does it is never written down.** `metistry connect claude-code` used to hand a session a way to capture into the vault and leave the reading half — the assistant's knowledge, under the grant the owner chose — to a command the owner had to assemble, with the bearer pasted into a config file in plain text. It now registers the console for Claude Code itself, naming the bearer by a variable Claude Code fills in when it starts from the Keychain-backed value, so no file `connect` writes and no command it runs ever holds the secret; the owner's own Claude Code settings are changed only by Claude Code's own command, never rewritten behind its back, and `connect --list` shows both halves and `connect --remove` takes the entry away again. Whether Claude Code really expands the variable was not assumed: a test runs the real tool against a probe server that records what it receives, and fails the build the day a release stops doing so. Every dev tool Metistry reaches is now one entry in a registry held to the same conformance rules, so reaching another harness is one entry, not a rewrite.

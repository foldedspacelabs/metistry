- 2026-10-19 — **A provider's tool arrives with the owner's choice, verified twice, and never with the install.** The owner ruled that Metistry may bundle the tools a remote-access provider needs — Tailscale's node, Cloudflare's connector, the zrok client — so that *sign in, authorize, done* needs no second download from a vendor's page. Each tool is now its own release asset: built or taken from a version pinned by digest, cross-checked against what the publisher itself records, its licence shipped beside it, and every executable signed under Folded Space Labs with the same rule as the bundled runtime and then checked, one by one, for that identity before the asset exists. A fresh install carries none of them; the Mac app's disk image carries none of them. Choosing a provider fetches exactly that provider's pack, and nothing is trusted until the release's checksum list and the pack's own manifest both agree — a mismatch of either kind, in transit or inside the archive, fails the set-up, writes no record, and leaves what was already on disk untouched to the byte. A pack is never moved backwards to an older release, an update moves forward only what the owner already chose, and an install kept off the network is told which tool to install by hand rather than left with a silent gap.

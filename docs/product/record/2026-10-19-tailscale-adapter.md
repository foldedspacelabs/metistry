- 2026-10-19 — **The phone's first way in: Tailscale Funnel, with the sign-in page behind the rate limits and the main port out of reach.** The recommended remote-access path now exists end to end. Choosing Tailscale brings a node onto the owner's tailnet — their own running Tailscale app when they have one, else the bundled unprivileged node, named for the instance so renaming the Mac changes nothing — signs it in through Tailscale's own page with completion read from the node's state rather than from anything typed, turns each one-click approval Tailscale asks for into the flow's one step, and publishes the console's proxy listener under a stable HTTPS name that a phone on cellular opens in Safari with no app. Three refusals make it safe to leave running: Funnel will not configure unless the console's proxy listener is the hardened one (its security headers are the proof), a handler that forwards to the console's main port is refused before a record exists and fails doctor by name if it drifts there later, and the record is written only after the public name resolves and the origin answers from this Mac — so a switch that cannot complete leaves the previous choice in force. Turning it off leaves no handler, a logged-out node and no state, and says what only the owner can remove at Tailscale.

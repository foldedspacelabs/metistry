- 2026-10-19 — **A token typed into a terminal is never shown, and nothing waits silently for a keystroke nobody was told about.** `connect-repo --auth token` used to promise a pasted GitHub token was "never echoed" while the terminal echoed every character of it; it now takes the same hidden prompt `secrets set` does. A request body or an agent's operating prompt, which are neither secret nor one line, now say on stderr that they end with Ctrl-D instead of hanging mute, and never put that instruction on stdout, where a script reads the result. Piped input behaves exactly as before. Each of the three is held by a test with a fake terminal that records what reached its screen.

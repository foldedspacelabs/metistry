# Inbox

Everything captured lands here: the share sheet, `/note` in the console, the
dev-tool plugins, and anything you drop in yourself. It is an ordinary folder
in this vault, so Obsidian can add to it and edit it like any other.

- **Write here freely.** A note you add, or an edit you make to one already
  here, is noticed by content hash and goes (back) into the triage queue —
  a refinement is new information, not noise.
- **Nothing is deleted behind you.** Triage files a proposal; you decide.
  Deleting a file here only archives its triage row.
- **Big files go to `.large/`.** Anything over the capture size threshold is
  written there instead, and git does not carry that folder — the file stays
  on this machine and in this vault, out of the repo's history.

Full story: `docs/ops/inbox.md` in the Metistry product repo.

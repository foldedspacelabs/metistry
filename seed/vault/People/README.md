# People

A page per person you work with, linked from tasks (`@[[Jim Fallon]]`) and
meeting notes. Nothing seeds these for you and nothing writes to them —
create one the first time you need to link someone, and Obsidian's own
backlinks pane shows every line that names them, for free.

Give a page an address and Today can link a meeting's attendee to it:

```yaml
---
email: jim.fallon@example.com   # or a list, one per address
---
```

Only an address a page of yours names is ever matched — never a name, never a
guess — and an address two pages both claim links to neither.
